# Hand tracking assets

The JavaScript and WebAssembly files are unmodified distribution files from Google's [MediaPipe Tasks Vision 0.10.21 npm release](https://www.npmjs.com/package/@mediapipe/tasks-vision/v/0.10.21), licensed under [Apache License 2.0](LICENSE.txt). Both the SIMD and baseline WASM binaries are included for browser compatibility.

The [hand landmarker model bundle, float16, version 1](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task) is distributed by Google for its [Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker).
